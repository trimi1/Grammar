
# Grammar

La grammaire contient toutes les infos nécéssaires aux autres projets afin qu'ils communique de manière fluide.




## Installation

La grammaire ne nécéssite aucune Installation car une version compilée de celle-ci 
(.jar) est déjà présente dans chaque projet qui en a besoin.
Cependant si vous vous voulez la compilée vous même voici les étapes :

- Cloner le projet depuis le répertoire distant : 
  git clone https://github.com/SxYxuse/Grammar.git
- Ouvrir le projet avec un IDE adéquat et exporter en .jar depuis le build.gradle ou alors exécuter la commande ./gradlew jar
    
## Exécution

Rien est à exécuter dans cette partie.
